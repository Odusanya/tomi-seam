- [ ] Every AI claim shows its source: doc, section, page. Click jumps to it.
- [ ] Confidence is visible (high / med / low) with the reason on hover.
- [ ] Accept / Reject / Edit are one key each (`a` `r` `e`).
- [ ] Reject and Edit need a reason; Confirm is disabled until it's typed.
- [ ] No source → Accept disabled, hint "Add a source to accept".
- [ ] After approval the item turns neutral; Undo is offered.
- [ ] AI work in progress shows narration ("Reading TD-118 · p.42"), not a bare spinner.
- [ ] Failure says what failed and offers Retry.
