1. Close the seam between DESIGN.md and the L1 primitives

Strong in-process

app/app-theme.css · components/ui/table.tsx · DESIGN.md · docs/yardsticks/type-density.md · polish.md

Before

DESIGN.md: body 13 px · rows 41 / 32 · controls 28
Table: text-sm 14 px, p-2 rows, row hover on
--spacing-row tokens: read by nothing
Call site: no-restyle blocks the fix

After

DESIGN.md names the variant, not the pixel

theme bridge + Table

--text-sm: 13px · td reads h-row · data-density="compact" · hover only on data-interactive

Problem. The rules, the tokens and the primitives disagree, and lint forbids fixing it where the caller stands.

Solution. Bridge type in the theme, make Table read the row tokens, and make the docs name sizes that exist.

  • locality: density lives in one module
  • leverage: every table is on-scale
  • 46 text-sm uses fixed by one line

3. Put the review invariants into the AIOutput interface

Strong in-process

lib/fixtures/types.ts · DESIGN.md · docs/yardsticks/hitl.md

Before

status: draft | accepted | rejected | edited

reviewedBy?: string

reason?: string // required when rejected

Docs say "approved"; the type says "accepted".

After

{ status: "draft" }

{ status: "accepted"; by }

{ status: "edited" | "rejected"; by; reason }

One word everywhere: accept.

Problem. "Override needs a reason" is a comment, so a fixture or a handler can break it silently.

Solution. A discriminated union on status.

  • the compiler holds DESIGN rule 3
  • locality: one vocabulary for review

4. Deepen fakeAI into one AI-run module

Worth exploring in-process

lib/fixtures/fake-ai.ts · hooks/use-fake-ai.ts (new) · lib/fixtures/types.ts

Before

flowchart TB
  A[Feature A] --> F[fakeAI: a timeout]
  B[Feature B] --> F
  A -.-> SA[own status union, narration timer, retry]
  B -.-> SB[own status union, narration timer, retry]
  classDef leak stroke:#dc2626,stroke-width:2px;
  class SA,SB leak

After

flowchart TB
  A[Feature A] --> H[useFakeAI: state, run]
  B[Feature B] --> H
  H --> F[fakeAI with steps]
  classDef deep fill:#0f172a,color:#fff;
  class H deep

Problem. Deletion test: remove fakeAI and nothing is lost. The hard part (running, narration, error, retry) reappears in every caller, where effects are banned.

Solution. fakeAI takes narration steps; one hook returns AIRun<T> and run.

  • leverage: four states per call
  • every AI block narrates the same way
  • one new file, about 30 lines
